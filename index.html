My name is Adebisi Mudashiru, and today I’ll be presenting my web project — ML Autos, a modern car e-commerce frontend web application.

Problem Statement

As part of our project, we were asked to create a modern-day e-commerce website using a provided sample template. The goal was to build a pixel-perfect replica of a fruit store and transform it into a new product-based design.

Many car buyers today struggle to find a platform that combines modern design with a simple, user-friendly interface for exploring cars. I wanted to address that.

Why I Chose This Project

I chose to create a car e-commerce website because I felt connected to the futuristic theme that cars represent. Cars give room for a techy and modern interface, which aligns with my design style and creativity.

ML Autos provides a sleek, dark-themed platform for car lovers. It focuses on simplicity, speed, and a clean design that makes exploring cars easy and enjoyable.

Creativity and Development

This project was developed using HTML, CSS, and Bootstrap to ensure responsiveness and structure. I incorporated icons from Font Awesome and Bootstrap Icons for better visuals.

I took a fruit-store layout and reimagined it for a car e-commerce site — adding new sections, a review area, and a dark futuristic theme that represents my unique creative approach.
